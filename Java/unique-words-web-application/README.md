# Unique Words Web Application

## About the Project

Unique Words is a Java EE web application developed to manage and store unique and non-unique words. The application provides functionality for working with words while using a database to maintain stored information.

This project demonstrates practical knowledge of Java web application development, database connectivity, persistence, and application server configuration.

## Technologies Used

- **Java** – Application development
- **Java EE** – Web application development
- **Java DB (Apache Derby)** – Database management and persistence
- **GlassFish Server** – Application server
- **NetBeans IDE** – Development environment
- **JPA** – Database persistence (if used in the project)

## Features

- Manage unique words and non-unique words.
- Store application data in a database.
- Retrieve previously stored words.
- Maintain data through database persistence.

## Database Configuration

The application uses Java DB (Apache Derby) as its database.
